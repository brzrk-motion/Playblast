# Sponsors

Playblast is sponsorship-first open source from Brzrk Interactive. Studios run free, self-hosted instances; sponsors fund maintenance, docs, and roadmap work so the tool stays MIT and independent of a hosted SaaS lock-in.

## Why sponsor

- Keep a motion-studio proofing stack that runs on your Docker host or Synology NAS
- Prioritize features that match real floor workflows (versions, comments, approvals, compare)
- Support operator docs, security response, and release-candidate hardening

## How to sponsor

1. Enable or use GitHub Sponsors for the brzrk-motion org (see .github/FUNDING.yml).
2. If Sponsors is not yet enabled on the org, use the funding link once maintainers turn it on — the YAML is ready.
3. Studio or vendor sponsorships (logo placement, roadmap conversation) can be arranged with maintainers; open a non-security discussion or contact channel listed on the org profile.

## What sponsorship is not

- Not a paid support contract or remote ops engagement
- Not multi-tenant hosted Playblast
- Not a promise of custom private forks inside the public MIT line

Operators still own Docker, networking, HTTPS/VPN, backups, and SMTP. See the README support boundary and docs/deployment/operator-responsibilities.md.
